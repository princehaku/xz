# 相机启动与授权

开机先显示联网/准备提示，Wi-Fi 连接和激活完成后才开放 AI Chat 与 AI Camera。SD Music 在此期间可离线使用。Wi-Fi 配网页的 BOOT 音乐入口继续保留。

直接进入相机后，按键拍照会先显示“正在连接识图服务”。固件通过协议连接获取本次 MCP `vision` 能力，确认视觉地址和授权已更新，才开始拍照上传。等待期间双击返回会取消本次请求；握手失败或超时会恢复预览并允许重试。已有近期有效的相机会话可以复用，识图结果播报使用同一连接，麦克风保持停止。

Wi-Fi、OTA 激活、协议 hello 和 MCP vision 更新各有独立的完成条件。NVS 保存的视觉配置不能代表本次授权已就绪；协议 hello 完成也不能替代 MCP vision 更新。

上传失败仅记录 HTTP 状态码，避免在诊断日志中输出凭据、完整请求头或响应正文。401/403 可用于判断鉴权问题，其他非 200 响应需要结合服务端日志确认；返回页面或一次上传失败后，下次拍照会重新准备会话。

SDMMC 保留 ESP-IDF 默认的带槽位参数清理标志；限制 1-bit 总线时仅关闭多线与 DDR 能力。无卡初始化失败、重扫和退出都会按驱动要求清理资源。首次读卡超时仍需核对卡片是否插入、接触和格式。
